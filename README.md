# 🌦️ KnowWeather

A lightweight, interactive weather application built with **HTML**, **CSS**, and **JavaScript** that lets users check the current weather with visual flair.

## 🔗 Live Demo
Check it out here: [KnowWeather on GitHub Pages](https://anjaneyakumar18.github.io/KnowWeather/)

## 📌 Overview
KnowWeather fetches real-time weather data and presents it alongside engaging animations like sunny skies, rain, or lightning—providing both information and ambiance. It's a visual and functional showcase of how front-end design and dynamic content can blend seamlessly.

## 🚀 Features
- **Real-Time Data**: Retrieves current weather using a weather API.  
- **Immersive UI**: Displays animations (e.g., rain, sunshine) matching live conditions.  
- **Responsive Design**: Works smoothly across desktop and mobile devices.  
- **Lightweight**: Built entirely with vanilla JavaScript—no external frameworks.  

## 🛠️ Tech Stack
- **HTML5** – Structure and layout  
- **CSS3** – Styling, responsiveness, and animations  
- **JavaScript (ES6)** – API calls, DOM updates, and event handling
